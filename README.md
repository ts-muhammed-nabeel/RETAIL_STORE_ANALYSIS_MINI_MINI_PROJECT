# RETAIL_STORE_ANALYSIS_MINI_PROJECT
📊 Retail Sales Analysis — Mini Project
📌 Project Overview

This mini project focuses on analyzing retail sales data to understand business performance, customer behavior, product sales, profitability, and order trends.

The project uses Microsoft Excel for data preparation and analysis and Power BI to create an interactive dashboard for visualizing key business insights.

🎯 Project Objective

The main objective of this project is to analyze retail sales data and identify:

Overall sales and profit performance
Top-performing products and categories
Customer purchasing behavior
Sales performance across regions
Monthly sales and profit trends
Order and quantity trends
Customer satisfaction
Returns and order status
Shipping performance

🔍 Analysis Performed
1. Sales Analysis

Analyzed total sales and identified sales trends across different months, regions, categories, and products.

2. Profit Analysis

Compared sales and profit to understand which products and categories contribute most to overall profitability.

3. Customer Analysis

Analyzed customers based on:

Gender
Age
Region
Purchasing behavior
Customer satisfaction
4. Product Analysis

Identified:

Top-selling products
Best-performing categories
Product-wise sales
Product-wise profitability
5. Order Analysis

Analyzed order status, returned orders, quantity sold, and order trends.

6. Shipping Analysis

Analyzed the number of days required to ship orders and evaluated shipping performance.
